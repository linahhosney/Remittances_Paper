# Remittances and Political Participation in MENA: Testing the Independence Channel Through Perceived Corruption

## Overview
This repository contains the analysis code for an independent research project examining whether remittance shapes political participation in Middle East and North Africa (MENA) households through the independence channel, and whether perceived corruption mediates this relationship.

## Research Question
Do remittances increase political participation in MENA, which forms of political participation, and does this effect vary based on perceived levels of corruption in the country?

## Data
This project uses data from the **Arab Barometer** survey, a non-partisan research network that conducts public opinion surveys across the Arab world.

The dataset is not included in this repository due to data use agreements. To access the data, register at [arabbarometer.org](https://www.arabbarometer.org/survey-data/data-downloads/).

## Methods
- Binary logistic regression
- Mediation analysis through perceived corruption
- R
